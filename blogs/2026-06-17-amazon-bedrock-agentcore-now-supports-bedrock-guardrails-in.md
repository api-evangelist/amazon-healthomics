Amazon Bedrock AgentCore added Bedrock Guardrails support in policy, giving enterprises advanced safety and access controls for scaling production AI agents. Policy provides authorization control over permitted agent actions, while Guardrails defend against top production and security risks including prompt injection and sensitive data exposure.
