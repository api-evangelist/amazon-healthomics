Oracle Database@AWS now supports Oracle Autonomous AI Database Serverless (ADB-S), a fully managed Oracle deployment on Exadata. ADB-S is distributed through public and private AWS Marketplace offerings with Provided and Included license options, delivering the Autonomous AI Database via AWS management, tooling, and APIs without dedicated Exadata provisioning.
