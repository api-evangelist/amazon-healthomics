AWS Security Agent, now part of AWS Continuum, added Kiro and Claude Code support so developers can launch security reviews directly within development environments. The agent validates code scanner findings through production simulation in isolated environments for exploitation verification, with new GitLab.com, GitLab Self-Managed, GitHub Enterprise, Bitbucket, and Confluence integrations.
