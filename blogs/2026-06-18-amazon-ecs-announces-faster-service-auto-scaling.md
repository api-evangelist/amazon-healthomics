Amazon ECS service auto scaling now reacts faster using high-resolution metrics recorded every 20 seconds. AWS internal tests measured scaling activation cut from 363 to 86 seconds (76% reduction) and full task provisioning from 386 to 109 seconds (72% reduction); target tracking for CPU and memory now supports 20-second intervals alongside 60-second options.
