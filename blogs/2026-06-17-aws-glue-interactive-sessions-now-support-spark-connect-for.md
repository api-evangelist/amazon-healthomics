AWS Glue Interactive Sessions added Apache Spark Connect support, letting developers build Spark applications from preferred environments including SageMaker Unified Studio notebooks, Jupyter, and Visual Studio Code on Glue infrastructure without managing it. Spark Connect decouples client operations from the rendering infrastructure for data exploration and iterative PySpark development.
