AWS Secrets Manager added safe secrets handling inside the aws-core extension of the Agent Toolkit for AWS, the open-source framework that equips AI agents with tools, knowledge, and guardrails for AWS development. It lets developers use secrets in agent workflows without exposing them in the underlying agent or conversation logs.
