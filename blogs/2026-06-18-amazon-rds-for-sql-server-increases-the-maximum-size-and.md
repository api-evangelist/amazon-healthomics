title: "Amazon RDS for SQL Server increases the maximum size and provisioned performance of General Purpose (gp3) volumes"

date: "2026-06-18"
author: "Amazon Web Services"
feed_url: "https://aws.amazon.com/about-aws/whats-new/recent/feed/"
---
Amazon RDS for SQL Server raised GP3 storage limits, letting individual volumes scale to 64 TiB (up from 16 TiB), 80,000 IOPS (up from 16,000), and 2,000 MiB/s throughput (up from 1,000 MiB/s). Additional volumes can be added per instance, raising aggregate capacity to 256 TiB per instance.
