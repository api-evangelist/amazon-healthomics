Amazon Bedrock AgentCore added optimization capabilities that turn production data into continuous agent improvement. Observability surfaces failure, goal, and trajectory details across many conversations, recommendation analysis reviews messages and evaluation outputs to suggest targeted agent and tool refinements, and validation tests suggestions against established evaluation sets before production.
