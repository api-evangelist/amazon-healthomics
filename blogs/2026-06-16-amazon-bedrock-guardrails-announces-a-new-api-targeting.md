Amazon Bedrock Guardrails added the InvokeGuardrailChecks API, a resourceless capability that enables individual safety enforcement at any point in agentic workflows. The API provides fine-grained, request-based control over active safeguards, returning numeric severity and confidence scores for custom thresholds and actions.
