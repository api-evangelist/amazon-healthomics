AWS expanded Ubuntu 24.04 LTS bundle availability for Amazon WorkSpaces Personal in the AWS China (Ningxia) region. The release provides updated Linux toolchains, package systems, and security improvements, with migration support for operators moving from older Amazon Linux 2 WorkSpaces.
