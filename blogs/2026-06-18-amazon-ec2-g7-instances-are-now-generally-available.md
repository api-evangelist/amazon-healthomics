AWS released G7 instances using NVIDIA RTX PRO 4500 Blackwell Server Edition GPUs, delivering up to 4.6x inference and 2.1x rendering performance over G6. Configurations support up to eight GPUs (32 GB each), Intel Xeon 6 CPUs, and 700 Gbps networking for translation, image analysis, voice recognition, recommendations, graphics, and game streaming.
