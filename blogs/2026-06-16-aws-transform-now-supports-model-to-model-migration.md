AWS Transform added model-to-model migration assessment that examines generative AI applications and generates modernization plans to move third-party provider implementations to Amazon Bedrock. It scans code, identifies each agent tool deployment, gathers requirements via questioning, and maps models to Bedrock replacements with cost analysis and production-ready changes.
