Amazon Connect now supports agent interruption, letting prioritized contacts override standard routing configurations. Examples include time-sensitive callback routing through personal extensions while agents handle other customers, plus direct assignment that overrides custom agent status, available across all regions supporting Amazon Connect Customer.
