AWS introduced bmn-cx3a instances on next-generation Outposts racks, the first AMD-based instances with accelerated networking on Outposts, using fifth-generation AMD EPYC processors at 4.1 GHz and NVIDIA ConnectX-7 networking with 800 Gbps bandwidth. Configurations span 256 vCPUs and 1.5 TB memory across two sizes (metal-32xl, metal-64xl) with 16 TB storage and native Layer 2 and PTP support.
