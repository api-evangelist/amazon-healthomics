Aurora MySQL-Compatible and RDS for MySQL now provide Extended Support for MySQL 5.7 through June 30, 2029, extended from the prior February 28, 2027 end date. Extended Support supplies critical security patches, production bug fixes, and AWS support, giving customers more upgrade planning time.
