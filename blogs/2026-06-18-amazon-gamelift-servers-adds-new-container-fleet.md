Amazon GameLift Servers added container fleet improvements for greater flexibility and inter-container communication. Developers can customize Linux capabilities for container specs beyond Docker defaults, and game servers can retrieve full networking details (name, ID, regional IP, instance type) using the new ListContainersNetworkInfo() capability.
