Amazon MQ for RabbitMQ now supports private networking, enabling secure connections to VPC-contained resources for federation, shovel operations, or authentication via internal LDAP/OAuth 2.0 sources. It uses VPC Lattice, AWS RAM, and PrivateLink, with AWS managing the underlying infrastructure instead of customer-built NLB and NAT Gateway setups.
